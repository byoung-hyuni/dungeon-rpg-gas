# 격투가·거너 추가와 기존 사용자 이벤트

이 변경은 로컬에서 구현했습니다. 운영 배포와 실제 보상 발송은 아직 실행하지 않았습니다.

## 추가한 직업

| 직업 | 기본 공격 | 시작 무기 | 스킬 |
|---|---|---|---|
| 격투가 | 검사보다 짧은 사거리에서 빠르게 3연타합니다. | 수련 장갑 | 솟구치는 주먹, 파고들기, 회오리 발차기, 기공탄, 투지, 진각, 백열연타 |
| 거너 | MP 소모 없이 사거리 460px의 탄환을 발사합니다. 기본 탄환은 첫 적을 맞히면 사라집니다. | 연습용 권총 | 관통탄, 돌파 사격, 회전 사격, 집중 포격, 정밀 조준, 폭발 유탄, 유성 포화 |

스킬 단축키와 습득 레벨은 검사와 같습니다. A/S/D/F/G/H/Q 키로 각각 레벨 1/3/6/10/14/18/23부터 사용합니다. 장비 착용 제한은 기존처럼 직업 공용이며, 공격 방식과 무기 그림은 직업에 따라 결정합니다.

## 보상 지급 방식

- 발송 메뉴를 처음 실행할 때 `Players`에 저장된 사용자 명단을 확정합니다. 저장하지 않은 캐릭터와 이후 가입자는 제외합니다.
- 대상자에게 5,000골드, HP 포션(`p_hp`) 100개, MP 포션(`p_mp`) 100개의 수령 권한을 발송합니다. 외부 메일이나 메시지를 보내는 기능은 아닙니다.
- 대상자는 로그인하면 마을에서 안내를 확인할 수 있습니다. 저장하면 보상을 받습니다. 이미 접속한 사용자도 다음 저장 때 받을 수 있습니다.
- 물약은 기존 99개 묶음 규칙을 따릅니다. 인벤토리 공간이나 골드 보유 한도가 부족하면 보상 전체를 보관합니다. 공간을 최대 4칸 비우고 골드를 999,994,999 이하로 만든 뒤 다시 저장하세요.
- 발송 명단은 `EventRecipients`, 수령 기록은 `Players.eventReward`에 남깁니다. 이벤트 ID는 `new_classes_20260929`입니다. 이 시트와 수령 기록을 지우면 중복 지급이나 대상 누락이 생길 수 있으므로 유지하세요.
- 저장 시 골드·물약·수령 기록을 하나의 행 쓰기로 반영합니다. 모든 지급 처리는 스크립트 잠금 안에서 실행합니다.
- 다른 접속에서 이미 수령했거나 저장 성공 응답을 받지 못했다면, 오래된 수령 상태로 보내는 저장을 거절합니다. 다시 로그인하면 서버에 저장된 보상을 확인할 수 있습니다. 그 접속의 미저장 진행은 자동 병합하지 않습니다.

## 운영 반영 순서

저장소의 배포 승인 규칙에 따라 승인 후 아래 순서로 진행합니다. 기존 게임 주소와 Script ID를 유지합니다.

1. `npm test`, `npm run build`, `npm run test:classes`를 실행합니다. Playwright를 별도 경로에 설치했다면 `PLAYWRIGHT_MODULE`에 모듈 경로를 지정하세요.
2. `npm run push`와 `npm run deploy -- "v1.1.0 격투가·거너와 기존 사용자 이벤트"`를 실행합니다. 기존의 미배포 관리자 함수 보안 수정도 함께 반영됩니다.
3. 운영 스프레드시트를 새로 열고 `🎮 던전 RPG > 격투가·거너 데이터 추가`를 실행합니다. Classes 2행, Skills 14행, Items 2행 중 없는 행만 추가합니다. 기존 설정이나 사용자·랭킹을 초기화하지 않습니다.
4. 게임을 새로 열어 세 직업이 보이는지 확인합니다.
5. `🎮 던전 RPG > 기존 사용자 이벤트 보상 발송`을 실행하고 확인 창에서 승인합니다. 표시되는 대상 인원과 `EventRecipients` 명단을 확인합니다. 이때 `Players.eventReward` 컬럼도 없는 경우 자동 추가합니다.
6. 배포 번호를 `CHANGELOG.md`에 기록하고 `package.json` 버전과 Git 태그를 맞춥니다. 실제 발송 인원과 시각을 `HANDOFF.md`에 기록합니다.

`게임 데이터를 초기값으로 되돌리기` 메뉴는 이번 변경에 사용하지 않습니다. 이미 운영 중인 밸런스 설정까지 바뀌기 때문입니다. 보상 수령 후에는 이전 서버 코드로 되돌리지 마세요. 이전 서버는 수령 상태를 확인하지 않고 저장하므로 보상 보호가 해제됩니다.

## 확인한 내용

서버 테스트에서 직업 저장, 기존 시트에 누락 항목 추가, 반복 실행, 구버전 Players 헤더 확장, 발송 대상 고정, PIN 검증, 중복 수령 방지, 오래된 저장 거절, 가방·골드 한도, 쓰기 실패 후 재시도를 확인했습니다.

브라우저 테스트에서 직업 선택 화면, 두 직업의 기본 공격과 스킬 14개, 보상 안내, 수령, 반복 저장, 재접속 후 잔액을 확인했습니다. 기존 검사 E2E에서도 첫·마지막 던전, 랭킹, 사망·부활, 재로그인을 확인했으며 브라우저 오류는 없었습니다. 스크린샷은 로컬 `tools/shots/`에 저장합니다.

첫 던전 자동 플레이에서는 격투가와 거너가 모두 레벨 1로 시작해 사망 없이 클리어했습니다. 각 49초, SSS 등급을 기록했습니다. 이는 한 번의 봇 실행 결과이며 두 직업의 전체 던전 밸런스 검증은 아닙니다.
